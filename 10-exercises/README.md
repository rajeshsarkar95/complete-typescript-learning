# TypeScript Exercises

Try these without looking up a solution first.

1. Create a typed `Book` object with `id`, `title`, and optional `author`.
2. Write `sum(numbers: number[]): number`.
3. Write a type guard that checks whether an unknown value is an array of strings.
4. Create a generic `wrapInArray<T>(value: T): T[]`.
5. Create `ApiResponse<T>` with `data`, `success`, and `message`.
6. Use `Pick` to create a public user profile without email.
7. Model success and failure using a discriminated union.
8. Write an exhaustive `switch` over `"pending" | "success" | "error"`.
9. Create a class with a private balance and a public deposit method.
10. Type a React form submit handler using `FormEvent<HTMLFormElement>`.
